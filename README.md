SOBRE O PROJETO

O Taverna 3D é um sistema desenvolvido para auxiliar no gerenciamento de uma empresa que trabalha com a produção e comercialização de produtos impressos em impressoras 3D, pertencente a Daniel Roberto de Souza Junior.

O objetivo do sistema é facilitar a organização e o controle das atividades da empresa, reunindo em um único ambiente as funcionalidades de cadastro de clientes, produtos, pedidos e pagamentos.

FUNCIONALIDADES

- Painel inicial para acesso às principais áreas do sistema.
- Cadastro e gerenciamento de clientes.
- Cadastro e consulta de produtos.
- Cadastro e gerenciamento de pedidos.
- Registro e gerenciamento de pagamentos.
- Navegação entre os módulos do sistema.

TECNOLOGIAS UTILIZADAS

O projeto foi desenvolvido utilizando:

- HTML5: utilizado para criar a estrutura das páginas do sistema.
- CSS3: utilizado para estilizar as páginas e organizar os elementos visuais.
- JavaScript: utilizado para implementar as funcionalidades e interações do sistema.

COMO EXECUTAR O PROJETO

1. Faça o download ou clone o repositório do projeto.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo index.html.
4. Abra o arquivo index.html em um navegador para visualizar e utilizar o sistema.
